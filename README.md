# Networking Notes

These are my notes that I have taken while watching [Jermey's IT Lab](https://www.youtube.com/playlist?list=PLxbwE86jKRgMpuZuLBivzlM8s2Dk5lXBQ), a course for the CCNA. These notes aren't for studying for the CCNA, but for learning networking concepts that I may need in cybersecurity. Learning how to configure cisco devices is probably overkill and out of scope for what I would do in the future so I did not focus too much on them. 

I had prior networking knowledge as I studied for the CCST-Networking for my IT magnet during high school. One of my issues when learning networking was how poorly explained the foundational concepts were, so for the first 3 lessons that I took notes for, there are some spots were I worded things differently as I wished that was the way a concept was explained when I first learned it. I do not intend these notes to be used by other people, so it's likely that the way I worded things don't make sense, or I was too elaborate on certain definitions when it might be already clear with a sentence or two for others.
